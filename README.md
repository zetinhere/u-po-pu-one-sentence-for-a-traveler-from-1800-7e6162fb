One sentence of 174 characters explaining the modern internet to a time traveler from 1800 — built only from things a person of that year already knows (a road, a post office, a library, a letter, ink, a book), with no word coined after their time. The program validates the sentence against the gate (1–200 characters, exactly one sentence, no post-1800 words) and writes it to `/output/entry.txt`.

> Imagine an unseen road joining every post office and library on earth, where your letter crosses the world before its ink dries and any book you seek lies open on your table.

## Run it

```sh
node main.ts
```
